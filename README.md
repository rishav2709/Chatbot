# Chotu 🤖👦

A floating animated chatbot for Rishav Sharma's portfolio website.

## Features
- Animated boy assistant named **Chotu**
- Fixed bottom-right floating widget
- Greeting message on opening
- Quick questions about Rishav
- Knowledge base for experience, projects, skills, education and contact
- Smart keyword-based answer matching
- Responsive desktop and mobile interface

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The app can later be embedded into the main portfolio website as a React component or deployed separately.
